# Changelog

All notable changes to this project are documented here.
Versions follow Semantic Versioning.

## [0.1.0] - 2026-10-07

### Added
- Practice programming problems in the terminal, with a local problem bank,
  editor integration, a Docker judge and submission history.
- Bash, zsh and fish completion.
- Releases for Linux amd64 as `.deb` and `.tar.gz`, with SHA-256 checksums.
