# Longest Common Subsequence

A subsequence keeps some characters of a string, in order, dropping the rest.
How long is the longest subsequence the two strings have in common?

## Input

Two lines, each with a string of lowercase letters.

- `1 ≤ |a|, |b| ≤ 2000`

## Output

The length of the longest common subsequence.

## Example

```
abcde
ace
```

```
3
```
