# Climbing Stairs

A staircase has `n` steps. Each move climbs 1, 2 or 3 steps. In how many
different orders of moves can you reach the top?

## Input

One line with `n`.

- `1 ≤ n ≤ 10^6`

## Output

The number of ways, modulo `10^9 + 7`.

## Example

```
4
```

```
7
```

(1+1+1+1, 1+1+2, 1+2+1, 2+1+1, 2+2, 1+3, 3+1)
