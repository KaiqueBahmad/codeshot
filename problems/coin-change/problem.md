# Coin Change

With an unlimited supply of each coin value, what is the fewest number of coins
that add up to `amount`?

## Input

The first line has `n` and `amount`. The second line has the `n` coin values.

- `1 ≤ n ≤ 100`
- `1 ≤ coin ≤ 10^4`
- `0 ≤ amount ≤ 10^4`

## Output

The fewest coins, or `-1` if `amount` cannot be made.

## Example

```
3 11
1 2 5
```

```
3
```
