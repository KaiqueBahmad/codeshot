# Valid Parentheses

A string made only of `()[]{}` is valid when every bracket is closed by a
bracket of the same kind, and brackets close in the reverse order they opened.

## Input

One line with the string `s`.

- `1 ≤ |s| ≤ 10^5`

## Output

`true` if `s` is valid, `false` otherwise.

## Example

```
([]{})
```

```
true
```
