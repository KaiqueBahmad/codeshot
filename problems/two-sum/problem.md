# Two Sum

Given a list of `n` integers and a `target`, find the two positions whose
values add up to `target`. Exactly one such pair exists, and a position cannot
be used twice.

## Input

The first line has `n` and `target`. The second line has the `n` integers.

- `2 ≤ n ≤ 10^5`
- `-10^9 ≤ a[i], target ≤ 10^9`

## Output

The two positions `i j`, 0-based, with `i < j`.

## Example

```
4 9
2 7 11 15
```

```
0 1
```
