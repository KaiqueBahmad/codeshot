# Maximum Subarray

Find the largest sum of a non-empty run of consecutive values.

## Input

The first line has `n`. The second line has the `n` integers.

- `1 ≤ n ≤ 2·10^5`
- `-10^9 ≤ a[i] ≤ 10^9` — the answer may not fit in 32 bits

## Output

The largest sum.

## Example

```
9
-2 1 -3 4 -1 2 1 -5 4
```

```
6
```
