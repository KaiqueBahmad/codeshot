# Number of Islands

A map is a grid of land (`#`) and water (`.`). An island is land cells joined
up, down, left or right. How many islands are there?

## Input

The first line has the number of rows `r` and columns `c`. Each of the next `r`
lines has `c` characters.

- `1 ≤ r, c ≤ 1000`

## Output

The number of islands.

## Example

```
4 5
##..#
#...#
..#..
...##
```

```
4
```
